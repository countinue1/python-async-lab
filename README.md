# python-async-lab

Python 异步编程学习实验（大模型应用开发求职备战 W1）。

## 实验列表

| 文件 | 内容 |
|---|---|
| test_async.py | asyncio.gather 并行任务入门 |
| test_async_model.py | 用 httpx 并发调用本地 Ollama 模型 |
| test_error.py | try/except/else/finally 异常处理 |
| test_json.py | json.dumps/loads/dump/load |
| test_file.py | with open 文件读写 |
| qa_saver.py | 综合项目：并行问模型 + 异常兜底 + 存 JSON |

## 运行环境

- Python 3.13
- Ollama + qwen2.5:7b（本地模型）
- `pip install httpx`
